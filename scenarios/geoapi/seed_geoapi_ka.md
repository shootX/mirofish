## ნაწილი 1. პროდუქტი: რა არის GeoAPI.ge

GeoAPI.ge არის ქართული ავტომობილების მონაცემების API. სლოგანი: „ბრენდები, მოდელები, თაობები და სპეციფიკაციები — ერთი API-ით“. სერვისს აწვდის შპს „ინოვა ლაბ“ (საიდენტიფიკაციო კოდი 432291851). კონტაქტი: hello@geoapi.ge. საიტი ორენოვანია (ქართული და ინგლისური).

### მონაცემების ექვსი დონე

1. ბრენდი: id, slug, name, synonyms[] (მაგ. „Тойота“), ლოგო ღია და მუქი ფონისთვის. `GET /brands`
2. მოდელი: brand_id, slug, name, markets[], generations_count. `GET /brands/{slug}/models`
3. თაობა: name, year_start, year_end, body_types[], chassis_code. `GET /models/{id}/generations`
4. მოდიფიკაცია: engine_volume_cc, transmission, drive_type, body_type. `GET /generations/{id}/modifications`
5. სპეციფიკაცია: ძრავი (მოცულობა, საწვავი, ცხენის ძალა), გადაცემათა კოლოფი, საწვავის ხარჯი ლ/100 კმ. `GET /modifications/{id}/specs`
6. კომპლექტაცია: standard / optional / not_available / unknown. `GET /modifications/{id}/equipment`

სულ 14–15 GET endpoint-ია, მათ შორის /engines, /bodies, /fuel, /colors, /models/{id}/years და /models/{id}/photo. ფილტრები: year_from, year_to, body, fuel, drive, transmission, q, modified_after. ერთ გვერდზე ნაგულისხმევად 100 ჩანაწერია, მაქსიმუმ 1000. ყოველ პასუხს ახლავს X-RateLimit-* და X-Quota-* სათაურები. შეცდომებს ერთი ფორმატი აქვს: `{error:{code,message}}`.

### ინტეგრაციის გზები

- **REST API**: JSON პასუხები და Bearer ავტორიზაცია საიდუმლო გასაღებით (`geoapi_sk_…`). გასაღები მხოლოდ სერვერზე უნდა იყოს. კოდის მაგალითები: cURL, JavaScript, Node.js, Python, PHP. ხელმისაწვდომია OpenAPI და Postman ფაილები.
- **ჩასაშენებელი ვიჯეტი**: ერთი ხაზი HTML (`<geoapi-filter public-key="…">`). ის საიტზე აჩვენებს კასკადურ არჩევანს: მარკა → მოდელი → წელი → თაობა → მოდიფიკაცია. იყენებს საჯარო გასაღებს (`geoapi_pk_…`) და მუშაობს მხოლოდ კაბინეტში მითითებულ https დომენებზე. ვიჯეტი საიტის განცხადებებს თავად არ ფილტრავს, მხოლოდ არჩეულ იდენტიფიკატორებს გადასცემს.
- **SDK, CLI და MCP (ახალი)**: TypeScript SDK და CLI (ვერსია 0.2.0) ჩამოიტვირთება geoapi.ge/downloads-დან. MCP სერვერი (geoapi.ge/mcp) AI ასისტენტებს უკავშირდება: Claude, Codex, Cursor. იყენებს იმავე გასაღებს, ლიმიტებსა და კვოტას.

### როგორ იწყება გამოყენება

1. რეგისტრაცია. Free გეგმა უფასოა და თვეში 1 000 წარმატებულ მოთხოვნას იძლევა.
2. ელფოსტის დადასტურება, რომლის გარეშეც საიდუმლო გასაღებს ვერ შექმნით.
3. პროექტისა და გასაღების შექმნა. გასაღები მხოლოდ ერთხელ ჩანს.
4. პირველი მოთხოვნა REST API-ით ან ვიჯეტით. ორივე ერთ მრიცხველს იყენებს.

## ნაწილი 2. სიმულაციის დაშვებები: ბაზარი და მომხმარებლები

> ქვემოთ მოცემული სიმულაციის სცენარია და არა კვლევის შედეგი. პერსონაჟები გამოგონილია.

### ბაზრის კონტექსტი (ზოგადი, დაშვება)

- საქართველოში მეორადი ავტომობილების იმპორტი და ხელახალი ექსპორტი დიდი სექტორია. აქტიურად მუშაობს ავტომობილების ონლაინ განცხადებების საიტები, ნაწილების მაღაზიები, სადაზღვევო და სალიზინგო კომპანიები, ავტოსერვისები.
- ბევრი ქართული საიტი მარკა/მოდელის სიებს ხელით ავსებს ან სხვაგან აკოპირებს. ხშირია ცარიელი ან შეუსაბამო ჩანაწერები.
- ავტომობილების საერთაშორისო მონაცემთა ბაზები, როგორც წესი, დოლარში ან ევროში ფასობს, უცხოური ბარათით იხდება და ქართული ინტერფეისი და მხარდაჭერა არ აქვს.
- ქართველი დეველოპერები ხშირად ფრილანსერები ან მცირე სააგენტოები არიან. ისინი ფასზე მგრძნობიარენი არიან და ახალ სერვისს ჯერ უფასო გეგმით ცდიან.
- დეველოპერული საზოგადოების დიდი ნაწილი Facebook-ის ჯგუფებში, Telegram-სა და LinkedIn-ზე საუბრობს. ახალ ქართულ სერვისს ხშირად სკეპტიკურად ხვდებიან და კითხულობენ: „ვინ დგას უკან?“, „დიდხანს იარსებებს?“, „მონაცემი საიდანაა?“.

### მომხმარებლის ტიპები (გამოგონილი პერსონაჟები)

1. **ლევანი, ფრილანს ვებ-დეველოპერი (თბილისი).** კლიენტებს ავტომობილების განცხადებების და ავტოსალონების საიტებს უკეთებს. სწრაფ ინტეგრაციას და ვიჯეტს აფასებს. ყოველ ლარს ითვლის და Free გეგმით დაიწყებს.
2. **ნინო, ავტომობილების განცხადებების დიდი პორტალის CTO.** დღეში ასობით ათას გვერდის ნახვას მართავს. მისთვის მთავარია მონაცემის სიზუსტე, uptime, SLA და ქეშირების უფლება. Growth ან Enterprise გეგმაზე იფიქრებს და VIN დეკოდირების არქონა აწუხებს.
3. **გიორგი, ავტონაწილების ონლაინ მაღაზიის მფლობელი (რუსთავი).** უნდა, რომ კლიენტმა „ჩემი მანქანისთვის შესაფერისი ნაწილი“ იპოვოს მოდიფიკაციის მიხედვით. ტექნიკური ცოდნა საშუალო აქვს და დეველოპერს დაიქირავებს. ფასს ლარში და ქართულ ინვოისს დადებითად აფასებს.
4. **თამარი, სადაზღვევო კომპანიის IT პროდუქტის მენეჯერი.** ონლაინ კალკულატორისთვის ძრავის სიმძლავრე და მოცულობა სჭირდება. აინტერესებს იურიდიული პირი, ხელშეკრულება, მონაცემთა უსაფრთხოება და შესყიდვის პროცედურა. „ავტომატური ჩამოჭრის არქონას“ ბიუროკრატიულ სირთულედ აღიქვამს.
5. **დავითი, ავტომობილების იმპორტიორი და ხელახალი ექსპორტიორი.** აშშ-ს აუქციონებიდან ჩამოყვანილ მანქანებს ყიდის რეგიონში. მისთვის მთავარი VIN-ით ძებნაა, რაც არ არის. სკეპტიკურია.
6. **ანა, სტარტაპის დამფუძნებელი.** ავტომობილების შედარების და „რომელი მანქანა ვიყიდო“ აპლიკაციას აწყობს. აინტერესებს საწვავის ხარჯი, კომპლექტაცია და ფოტოები, და MCP/AI ინტეგრაციით აღფრთოვანებულია.
7. **ირაკლი, სენიორ backend დეველოპერი, სკეპტიკოსი.** Facebook-ის დეველოპერულ ჯგუფში ხშირად წერს. კითხულობს, საიდან მოდის მონაცემები, აქვს თუ არა ლიცენზია და რა მოხდება, თუ სერვისი დაიხურება. ადარებს უფასო ღია წყაროებს.
8. **მარიამი, ტექნოლოგიური ბლოგერი და იუთუბერი.** ქართულ სტარტაპებს მიმოიხილავს. „ქართული პროდუქტის“ ისტორია უყვარს, თუმცა კრიტიკულ კითხვებსაც სვამს.
9. **სალომე, ოფიციალური დილერის მარკეტინგის მენეჯერი.** საიტზე მოდელების კონფიგურატორი უნდა. ფოტოების ცოტა რაოდენობა და ზომების არქონა აწუხებს.
